# Verified token vesting examples

See [partner permissions and review boundaries](../../PERMISSIONS.md). Wallet signatures, token approvals and local request review are your own authorization; asset policies, actual fee rights and administrator actions retain their contract checks.

See the [complete runnable guide](https://docs.ammora.org/guides/vesting). Commands are offline/read-only
or unsigned by default. Create and claim require fresh SDK plans, explicit caller
and review hash; approvals and creation remain separate transactions.
